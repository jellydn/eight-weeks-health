# Eight Weeks Health

A privacy-friendly, mobile-first 56-day wellness tracker.

## Features
- Editable height, weight, waist and start date
- BMI and adjustable initial weight target
- Eight-week progressive step targets
- Daily walking, meals, water, sleep and optional fasting checklist
- Illustrated strength workout checklist with step-by-step instructions
- Walking/recovery days and progressive strength frequency
- 56-day calendar, daily weight and steps
- Local browser storage and JSON export/import

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages (Settings → Pages → Deploy from a branch → main/root).

Data is stored only in the browser on each device; it does not automatically sync across devices.

General wellness information, not medical advice.
